## Getting Started

### Creating an Account

1. Open the Finance App
2. Tap **"Create Account"** on the welcome screen
3. Enter your information:
   - Full Name
   - Email Address
   - Password (minimum 8 characters)
4. Tap **"Register"**
5. You'll be automatically logged in

### Logging In

1. Open the Finance App
2. Enter your email and password
3. Tap **"Login"**
4. You'll be taken to the home screen

### First Time Setup

After logging in for the first time:

1. Review the app tour (optional)
2. Set your preferred currency
3. Configure notification preferences
4. Start adding your financial data

## Managing Expenses

### Adding an Expense

1. Tap the **"+"** button on the home screen
2. Select **"Add Expense"**
3. Fill in the details:
   - Description (e.g., "Office supplies")
   - Amount (in USD, SYP, or TRY)
   - Date
   - Category (optional)
4. Optionally attach an invoice:
   - Tap **"Add Invoice"**
   - Take a photo or select from gallery
5. Tap **"Save"**

1. Go to the **Expenses** tab
2. Browse your expense list

## Offline Mode

### How Offline Mode Works

Finance App works seamlessly even without an internet connection:

1. **Viewing Data**: You can view all your previously loaded data offline
2. **Creating Records**: New expenses, transfers, and incoming funds are saved locally
3. **Editing Records**: Changes are saved locally
4. **Automatic Sync**: When you're back online, all changes sync automatically

### Sync Status Indicators

- **Green Cloud**: Data is synced
- **Orange Cloud**: Pending sync
- **Blue Sync Icon**: Currently syncing
- **Red Error Icon**: Sync failed (will retry)

### Manual Sync

To manually trigger a sync:

1. Pull down on any list to refresh
2. Or go to **Profile** → **Sync Now**

### Viewing Pending Changes

1. Go to **Profile**
2. Tap **"Sync Status"**
3. View pending operations
4. See sync progress

## Troubleshooting

### "Session Expired" Error

**Problem**: You see "Your session has expired. Please log in again."

**Solution**:
1. Tap **"OK"**
2. Log in again with your credentials
3. Your data will be preserved

### "No Internet Connection" Message

**Problem**: You see "No internet connection" message

**Solution**:
1. Check your WiFi or mobile data
2. Try toggling airplane mode on and off
3. Your changes are saved locally and will sync when online

### "Sync Failed" Status

**Problem**: Some items show "Sync failed" status

**Solution**:
1. Check your internet connection
2. The app will automatically retry
3. If it persists, try manual sync from Profile

### "Access Denied" Error

**Problem**: You see "You do not have permission to perform this action"

**Solution**:
- This feature requires admin access
- Contact your administrator if you need access

### App is Slow

**Problem**: App is running slowly

**Solution**:
1. Close and reopen the app
2. Clear cache: Profile → Settings → Clear Cache
3. Ensure you have a stable internet connection
4. Update to the latest version

### Invoice Upload Failed

**Problem**: Invoice image won't upload

**Solution**:
1. Check your internet connection
2. Ensure image is less than 10MB
3. Try taking a new photo
4. The app will retry automatically

## FAQ

### General Questions

**Q: Is my data secure?**
A: Yes, all data is encrypted in transit using HTTPS, and your password is securely hashed. We never store your password in plain text.

**Q: Can I use the app offline?**
A: Yes! The app works fully offline. Your changes will sync automatically when you're back online.

**Q: How do I delete my account?**
A: Go to Profile → Settings → Delete Account. Note: This action cannot be undone.

**Q: Can I export my data?**
A: Yes, admins can export data to PDF or Excel. Regular users can view and screenshot their data.

### Expenses

**Q: Can I add expenses in multiple currencies?**
A: Yes, you can add amounts in USD, SYP, and TRY for each expense.

**Q: What file formats are supported for invoices?**
A: JPG, PNG, and PDF files are supported. Images are automatically compressed.

**Q: How many expenses can I add?**
A: There's no limit to the number of expenses you can add.

### Transfers

**Q: What is exchange information?**
A: Exchange information tracks currency conversion details when you transfer money and exchange it to another currency.

**Q: Can I edit a transfer after creating it?**
A: Yes, you can edit any transfer at any time.

### Sync

**Q: How long does sync take?**
A: Sync is usually instant. Large batches may take a few seconds.

**Q: What happens if sync fails?**
A: The app will automatically retry with exponential backoff. Your data is safe locally.

**Q: Can I see what's pending sync?**
A: Yes, go to Profile → Sync Status to see pending operations.

### Admin

**Q: How do I become an admin?**
A: Admin access is granted by the system administrator. Contact them for access.

**Q: Can I see other users' data?**
A: Only admins can see system-wide data. Regular users only see their own data.

## Tips & Best Practices

### Data Entry

1. **Be Descriptive**: Use clear descriptions for easy searching
2. **Add Invoices**: Attach receipts for important expenses
3. **Use Categories**: Organize expenses by category
4. **Regular Updates**: Update your data regularly for accuracy

### Offline Usage

1. **Sync Before Going Offline**: Ensure latest data is downloaded
2. **Monitor Sync Status**: Check sync status regularly
3. **Avoid Large Uploads Offline**: Wait for WiFi for large invoice uploads

### Security

1. **Use Strong Password**: At least 8 characters with mix of letters and numbers
2. **Log Out on Shared Devices**: Always log out when using shared devices
3. **Keep App Updated**: Update to latest version for security patches

### Performance

1. **Clear Cache Periodically**: Clear cache if app feels slow
2. **Limit Invoice Sizes**: Compress large images before uploading
3. **Use Filters**: Use date filters to load less data at once
