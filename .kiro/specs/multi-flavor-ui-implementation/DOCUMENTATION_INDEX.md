## Glossary

### Common Terms

- **Flavor**: A variant of the app (Superadmin, Admin, or User)
- **Group Code**: 6-character code for joining groups
- **Financial Box**: Multi-currency balance display
- **Invoice**: Expense receipt/photo attachment
- **Exchange Log**: Historical record of currency exchanges
- **Export Bundle**: PDF containing all invoice images
- **DTO**: Data Transfer Object for API communication
- **BLoC**: Business Logic Component (state management)

### Currency Codes

- **USD**: United States Dollar
- **SYP**: Syrian Pound
- **TRY**: Turkish Lira

### Role Hierarchy

```
Superadmin
    ├── Admin 1
    │   ├── User 1
    │   ├── User 2
    │   └── User 3
    └── Admin 2
        ├── User 4
        └── User 5
```
