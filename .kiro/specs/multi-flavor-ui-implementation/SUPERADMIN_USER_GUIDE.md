## Getting Started

### What is the Superadmin Role?

As a Superadmin, you are at the top of the organizational hierarchy. You can:
- Manage multiple Admin users
- Transfer funds to Admins
- View analytics across all Admin groups
- Monitor organizational financial activity

### Navigation Overview

The Superadmin app has five main sections:
- **Group Management**: View and manage your Admin users
- **Cash**: Manage your financial box and add incoming funds
- **Transfers**: Transfer USD to Admins
- **Analytics**: View organizational statistics and reports
- **Profile**: Manage your account settings

## Registration and Login

### First-Time Registration

1. Open the Superadmin app
2. Tap "Register" on the welcome screen
3. Fill in your details:
   - Full Name
   - Email Address
   - Password (minimum 8 characters)
   - Organization Name
   - Admin Group Name
4. Tap "Register"

**Important**: After successful registration, you will receive a unique 6-character group code. **Save this code securely** - Admins will need it to join your organization.

### Copying Your Group Code

After registration, a dialog will display your group code with a "Copy" button. You can also find your group code later in the Group Management page.

### Logging In

1. Open the Superadmin app
2. Enter your email and password
3. Tap "Login"

## Group Management

### Viewing Your Admins

The Group Management page is your home screen. Here you can:
- See the total number of Admins in your group
- View each Admin's profile picture, name, and email
- Access detailed financial information for each Admin

### Viewing Admin Details

1. Tap on any Admin card
2. A detail sheet will open showing:
   - Admin's name and email
   - Financial box balances (USD, SYP, TRY)
   - Last updated timestamp

### Sharing Your Group Code

1. Navigate to Group Management
2. Your group code is displayed at the top
3. Tap the "Copy" button to copy it to clipboard
4. Share this code with new Admins who need to join your organization

### Regenerating Your Group Code

If your group code is compromised:
1. Navigate to Group Management
2. Tap the "Regenerate Code" button
3. Confirm the action
4. A new 6-character code will be generated
5. Share the new code with your Admins

**Warning**: Old codes will no longer work after regeneration.

### Removing an Admin

1. Navigate to Group Management
2. Tap on the Admin you want to remove
3. In the detail sheet, tap "Remove from Group"
4. Confirm the action

**Note**: Removing an Admin does not delete their account, only removes them from your group.

## Financial Box (Cash)

### Viewing Your Balances

The Cash page displays your current balances in three currencies:
- USD (United States Dollar)
- SYP (Syrian Pound)
- TRY (Turkish Lira)

Each balance shows:
- Current amount
- Currency symbol
- Last updated timestamp

### Adding Incoming Funds

As a Superadmin, you can manually add incoming USD to your financial box:

1. Navigate to Cash page
2. Tap "Add Incoming" button
3. Enter the amount in USD
4. Add a description (optional)
5. Select the date
6. Tap "Save"

Your USD balance will be updated immediately.

### Understanding Balance Updates

Your balances update automatically when you:
- Add incoming funds (USD increases)
- Transfer funds to Admins (USD decreases)

## Transfers

### Creating a Transfer to an Admin

1. Navigate to Transfers page
2. Tap the "+" or "New Transfer" button
3. Fill in the transfer details:
   - **Recipient**: Select an Admin from your group
   - **Amount**: Enter amount in USD
   - **Date**: Select transfer date
   - **Notes**: Add optional notes
4. Review the details
5. Tap "Create Transfer"

**Important**: The system will verify you have sufficient USD balance before creating the transfer.

### Viewing Transfer History

The Transfers page shows all your outgoing transfers to Admins, including:
- Recipient Admin name
- Amount transferred
- Transfer date
- Status

### Filtering Transfers

Use filters to find specific transfers:
1. Tap the filter icon
2. Select filters:
   - **Recipient Admin**: Filter by specific Admin
   - **Date Range**: Select start and end dates
3. Tap "Apply"

### Exporting Transfers

1. Apply any desired filters
2. Tap "Export to PDF"
3. The export will include all filtered transfers
4. Save or share the PDF file

## Analytics

### Understanding the Analytics Dashboard

The Analytics page provides insights into your organization's financial activity.

#### Global Summary Card

Shows organization-wide totals:
- **Total Invoices**: Count of all expenses across all Admin groups
- **Total Invoice Value**: Sum of all expense amounts
- **Total Transfers**: Count of all transfers (incoming + outgoing)

#### Admin Group Analytics

Each Admin group shows:
- Admin name
- Number of users in their group
- Invoice count from their group
- Total invoice value
- Transfer count

### Filtering Analytics

1. Tap the filter icon
2. Select time period:
   - Last 15 days
   - Last month
   - All time
3. Filter by specific Admin group (optional)
4. Tap "Apply"

### Exporting Analytics

1. Apply desired filters
2. Choose export format:
   - **Export to PDF**: Formatted report
   - **Export to Excel**: Spreadsheet format
3. Save or share the file

## Profile Management

### Viewing Your Profile

Navigate to Profile to see:
- Your name and email
- Organization name
- Group code
- Account creation date

### Updating Profile Information

1. Navigate to Profile
2. Tap "Edit Profile"
3. Update your information:
   - Full name
   - Organization name
4. Tap "Save"

**Note**: Email cannot be changed after registration.

### Changing Password

1. Navigate to Profile
2. Tap "Change Password"
3. Enter:
   - Current password
   - New password
   - Confirm new password
4. Tap "Save"

### Language Settings

1. Navigate to Profile
2. Tap "Language"
3. Select your preferred language:
   - English
   - Arabic (العربية)
4. The app will restart with the new language

### Logging Out

1. Navigate to Profile
2. Scroll to bottom
3. Tap "Logout"
4. Confirm the action

**Note**: All local data will be cleared on logout.

## Troubleshooting

### Common Issues

#### "Insufficient Balance" Error

**Problem**: Cannot create transfer due to insufficient USD balance.

**Solution**: 
1. Check your current USD balance in Cash page
2. Add incoming funds if needed
3. Try the transfer again

#### Admin Not Appearing in List

**Problem**: An Admin who joined is not visible in Group Management.

**Solution**:
1. Pull down to refresh the list
2. Check that the Admin used the correct group code
3. Verify the Admin completed registration successfully

#### Cannot Export Data

**Problem**: Export button doesn't work or file doesn't download.

**Solution**:
1. Check your internet connection
2. Ensure you have storage permissions enabled
3. Try exporting again
4. If problem persists, contact support

#### Group Code Not Working

**Problem**: Admins cannot join using your group code.

**Solution**:
1. Verify you're sharing the correct 6-character code
2. Check if the code was recently regenerated
3. Try regenerating a new code
4. Ensure Admins are using the Admin flavor app

### Performance Issues

#### App Running Slowly

**Solutions**:
- Close and restart the app
- Clear app cache in device settings
- Ensure you have stable internet connection
- Update to the latest app version

#### Data Not Loading

**Solutions**:
1. Check internet connection
2. Pull down to refresh
3. Logout and login again
4. Contact support if issue persists

### Security Best Practices

1. **Keep Your Group Code Secure**: Only share with trusted Admins
2. **Use Strong Password**: Minimum 8 characters with mix of letters, numbers, symbols
3. **Regular Password Changes**: Change password every 3-6 months
4. **Logout on Shared Devices**: Always logout when using shared devices
5. **Monitor Admin Activity**: Regularly review analytics for unusual patterns

### Getting Help

If you encounter issues not covered in this guide:

1. **Check Documentation**: Review this guide and other documentation
2. **Contact Support**: Email support@financeapp.com
3. **Report Bugs**: Use the "Report Issue" option in Profile settings

## Appendix

- **Pull to Refresh**: Swipe down on any list to refresh data
- **Back Navigation**: Use device back button or swipe from left edge

- Data syncs automatically when online
- Offline changes are queued and synced when connection restores
- Pull to refresh to manually sync latest data

### Privacy and Data

- Your data is encrypted in transit and at rest
- Only you can see your financial box details
- Admins cannot see your detailed transactions
- Analytics show aggregated data only

- App updates are released regularly
- Update notifications appear in the app
- Always use the latest version for best experience and security
