## Typography

### App Name
- **Font**: System default (Roboto/SF Pro)
- **Weight**: Bold (700)
- **Size**: 28sp / 24pt
- **Color**: Primary Blue (#0175C2)
- **Letter Spacing**: 1.2

### Tagline
- **Font**: System default
- **Weight**: Regular (400)
- **Size**: 16sp / 14pt
- **Color**: Text Light (#757575)
- **Letter Spacing**: 0

### Arabic Text
- **Font**: Amiri (custom font)
- **Weight**: Bold for titles, Regular for body
- **Direction**: RTL
- **Size**: Same as English

## Accessibility

### Contrast Ratios
- Logo on white: ✅ AAA (7.5:1)
- Primary text: ✅ AAA (16.1:1)
- Secondary text: ✅ AA (4.6:1)

### Touch Targets
- Logo (non-interactive): N/A
- Buttons: 48dp minimum ✅
- Form fields: 48dp minimum ✅

### Screen Reader
- Logo: Decorative, no alt text needed
- App name: Announced as "MyFinance"
- Tagline: Announced in context

## Multi-User Visual Cues

The logo design specifically communicates multi-user capability through:

1. **Multiple Person Icons**: Two semi-transparent person icons in the background
2. **Central Wallet**: Shared financial management
3. **Gradient Effect**: Connectivity and collaboration
4. **Overlapping Elements**: Multiple users working together

## Responsive Behavior

### Small Screens (< 360dp)
- Logo: 80px → 60px
- Text: Smaller font sizes
- Spacing: Reduced padding

### Medium Screens (360-600dp)
- Logo: Standard sizes
- Text: Standard sizes
- Spacing: Standard padding

### Large Screens (> 600dp)
- Logo: Can scale up to 150px
- Text: Larger font sizes
- Spacing: Increased padding

### Tablets
- Logo: Centered with more space
- Text: Larger, more readable
- Layout: More spacious

## Brand Guidelines Summary

### Do's ✅
- Use the official logo on all auth screens
- Maintain consistent sizing
- Use primary blue (#0175C2)
- Include tagline on welcome/splash
- Support both English and Arabic
- Ensure proper spacing
- Use gradient backgrounds

### Don'ts ❌
- Don't distort the logo
- Don't change the color scheme
- Don't remove the multi-user icons
- Don't use low-resolution versions
- Don't add effects not in guidelines
- Don't use on busy backgrounds
- Don't mix with other branding
