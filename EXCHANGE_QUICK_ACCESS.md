# Exchange Feature - Quick Access Guide

## 🚀 How to Access Exchange Feature

### Option 1: View Exchange History
**Fastest way to see all exchanges**

1. Open the app
2. Look at bottom navigation bar
3. Tap the **Currency Exchange icon** (💱) on the right
4. View your exchange history

### Option 2: Create Exchange from Transfer
**Best way to exchange money from a transfer**

1. Open the app
2. Tap **Cash Inbox** (first icon in bottom nav)
3. Go to **Transfers** tab
4. Find the transfer you want to exchange
5. Tap the **three-dot menu** (⋮) on the transfer
6. Select **"Add Exchange"**
7. Fill in the exchange details
8. Tap **"Create Exchange"**

## ✨ Quick Tips

- **Balance Check**: The Create Exchange page shows remaining balance
- **Validation**: Can't exchange more than available balance
- **Auto-Calculate**: SYP amount calculates automatically
- **Pull to Refresh**: Swipe down on Exchange History to refresh
- **Date Picker**: Can't select future dates for exchanges

## 🔑 Key Features

### Exchange History Page
- See all your exchanges
- View amounts in USD and SYP
- Check exchange rates
- See transaction dates
- Pull to refresh

### Create Exchange Page
- Pre-filled transfer info

## 🎯 Common Tasks

### Task: Check how much I've exchanged
1. Tap Exchange History icon (bottom nav)
2. View list of all exchanges

### Task: Exchange money from a transfer
1. Go to Cash Inbox → Transfers
2. Tap menu on transfer → Add Exchange
3. Enter amount and rate
4. Create exchange

### Task: See remaining balance on a transfer
1. Go to Cash Inbox → Transfers
2. Look at transfer amount (shows remaining)
3. Or tap "Add Exchange" to see detailed balance

## ⚠️ Important Notes

- ✅ Can only exchange from transfers with remaining balance
- ✅ Cannot exchange more than available amount
- ✅ Cannot select future dates
- ✅ Exchange rate is required
- ✅ Changes are saved immediately
- ✅ Data syncs with server

## 🆘 Need Help?

**Can't see Exchange History icon?**
- Check you're on the home screen
- Look at the rightmost icon in bottom navigation

**Can't create exchange?**
- Verify transfer has remaining balance
- Check all required fields are filled
- Ensure amount is valid (positive, not exceeding balance)
- Check internet connection

**Exchange not showing?**
- Pull down to refresh
- Check network connection
- Verify you're logged in
